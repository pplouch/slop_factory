# Feature backlog 6: night visibility, debug menu, minimap fix, automated tests

_Historical record for [Rogue idle slop factory survivor rpg ultimate](../../CLAUDE.md) — what landed and why, kept for provenance, not needed for day-to-day work._

## Night visibility, debug menu, minimap fix, and automated tests (post-visual-polish)

A follow-up ad hoc request: torches on units + a bit of building light (night was still "really dark" even after the previous pass's brightness tuning), a more complete debug menu (clear fog / change time of day / add lots of resources / spawn enemies near base), a minimap border bug, and gdUnit4 + a real regression test suite ("ensure everything remains unbroken").

- **Blob torches**: `blob.tscn` gained a small code-built torch (stick + emissive flame + `OmniLight3D`) attached to `Visuals/LeftArmPivot` (not the right arm, which is reserved for the melee attack-swing animation) -- swings naturally with the arm's own gait animation for free. `Blob._ready()` now also calls `GemSparkle.apply_to_emissive_meshes(self)` so the flame gets the same animated flicker every ore/crystal already has, rather than a static glow.
- **Building ambient light**: `BuildableStructure` gained a Template Method hook, `_emits_ambient_light()` (default `true`), and `_spawn_building_light()` -- called from `_apply_construction_visual` the instant a structure finishes (`fraction >= 1.0`), never while still under construction, and only once (guarded by `_building_light == null`). `LinkableBuilding` overrides the hook `false`, since Wall/BeltSegment/Pipe/Road are numerous factory-grid pieces rather than "buildings" in the sense the ask meant, and a long belt/wall line would otherwise add up to dozens of real-time lights for no real visual benefit.
- **Debug menu additions** (`DebugMenu`/`DebugOverlayManager`/`FogManager`/`DayNightManager`/`SpawnManager`): "Clear Fog" (new `FogManager.reveal_all()`, marks the whole tracked map revealed at once); 4 time-of-day buttons -- Dawn/Noon/Dusk/Night -- wired to a new `DayNightManager.set_time_fraction(fraction)` (jumps within the *current* day, preserving `current_day()`'s own count, and re-applies lighting immediately); "Add Resources" expanded from the original wood/stone/planks trio to every gatherable/craftable resource type in the game (`DebugOverlayManager.DEBUG_RESOURCE_TYPES`) at a much larger flat amount (500, up from 100); "Spawn Enemies Near Base" (new `SpawnManager.spawn_enemies_near_base(count)`, a ring around the Town Hall or the map origin if none is built yet, kind picked from the whole `EnemyKinds` roster -- the same shape as `DayNightManager`'s own periodic wave, just player-triggered on demand).
- **Minimap border-dot bug**: root cause was `Minimap`'s `Display` `Control` never setting `clip_contents = true` -- `_world_to_local` clamps an off-screen entity's position to this control's own edge (0 or `size`), so a `draw_circle` there still spills `radius` pixels past the true border into whatever's behind the minimap panel, landing outside the region the fog overlay's own `draw_texture_rect_region` call is confined to (hence "partially covered by fog, but not entirely -- it's partially out of the minimap"). Fixed with one property (`clip_contents = true` in `minimap.tscn`), which makes Godot itself discard any draw call spilling past the control's rect.
- **gdUnit4 + test suite**: installed `addons/gdUnit4` (v6.2.0, downloaded from the project's GitHub releases and enabled in `project.godot`'s `[editor_plugins]`) and a real regression suite under `res://tests/` (21 suites, 92 test cases, all passing as of this writing) covering every autoload (`GameManager`/`Biomes`/`BlobKinds`/`BuildingKinds`/`EnemyKinds`/`Effects`/`MetaProgression`), the `core/` stateless helpers (`TaskLock`/`GridDirections`/`MaterialUtil`/`GemSparkle`/`PropScatter`/`AmbientParticles`/`BuildableStructure`'s ambient-light hook), the newer world managers (`DayNightManager`/`FogManager`/`SpawnManager`), `Chunk`'s volcanic ember mask, `Minimap`'s clip-contents fix, `DebugMenu`'s button-to-signal wiring, and `Blob`'s torch. See "Running and validating" above for the exact CLI invocation and the gotchas hit writing these (float32 shader-uniform round-tripping, `:=` type inference on duck-typed fields, and -- most importantly -- never letting a test suite touching `MetaProgression` actually overwrite the player's real save file).
